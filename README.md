# 소통을 중요시하는 성실한 개발자 입니다.

안녕하세요. 프론트엔드 개발자 황호태입니다.

사용자 관점에서 더 편리한 경험을 만드는 것을 목표로, 작동하는 UI를 넘어 흐름과 맥락까지 고민합니다.

협업 과정에서는 문제를 빠르게 정리해 공유하고, 코드 품질과 유지보수성을 높이는 리팩토링·정리 작업도 적극적으로 맡습니다.

성실함을 기반으로 꾸준히 성장하며 팀과 제품에 확실한 기여를 만드는 개발자가 되겠습니다.
