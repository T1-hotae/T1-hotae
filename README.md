# 소통을 중요시하는 개발자 입니다.

안녕하세요. 프론트엔드 개발자 황호태입니다.

사용자가 더 편하게 쓸 수 있는 경험을 만들기 위해 화면 구성뿐 아니라 사용 흐름과 맥락을 함께 고민합니다.

협업에서는 이슈를 빠르게 정리해 공유하고, 리팩토링과 코드 정리로 품질과 유지보수성을 높이는 일도 꾸준히 해왔습니다.

맡은 일을 책임감 있게 마무리하며, 팀과 제품에 실질적인 도움이 되는 개발자가 되고자 합니다.
